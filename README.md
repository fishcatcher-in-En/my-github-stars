## 关于这个仓库

- 数据由 [`scripts/fetch_stars.py`](scripts/fetch_stars.py) 通过 GitHub API 拉取，README 由 [`scripts/build_readme.py`](scripts/build_readme.py) 生成，请不要手动修改 README。
- 分类和点评写在 [`data/categories.json`](data/categories.json) 里，新 Star 的项目会先出现在「未分类」。
- GitHub Actions 每天自动更新一次，也可以在 Actions 页面手动运行。

想给自己也做一个？Fork 本仓库，改好 `data/categories.json`，再到 Actions 页面启用工作流即可，用户名会自动用你的。
